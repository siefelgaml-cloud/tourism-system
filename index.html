// دالة محدثة لحساب وتنسيق كروت الـ Dashboard بترتيب ثابت ومحمي من تداخل النصوص function updateCreditDashboardAndSummary(records) { let totalsByCurrency = { 'EGP': { deposit: 0, deduction: 0 }, 'USD': { deposit: 0, deduction: 0 }, 'EUR': { deposit: 0, deduction: 0 } }; let entityBalances = {}; records.forEach(item => { let curr = (item.currency || 'EGP').toUpperCase(); if (curr === 'EIUR') curr = 'EUR'; // توحيد الرمز const entity = (item.entity || 'غير محدد').trim(); const amt = parseFloat(item.amount) || 0; if (!totalsByCurrency[curr]) { totalsByCurrency[curr] = { deposit: 0, deduction: 0 }; } if (item.type === 'deposit') totalsByCurrency[curr].deposit += amt; else if (item.type === 'deduction') totalsByCurrency[curr].deduction += amt; const key = `${entity}___${curr}`; if (!entityBalances[key]) { entityBalances[key] = { entity, currency: curr, deposit: 0, deduction: 0 }; } if (item.type === 'deposit') entityBalances[key].deposit += amt; else if (item.type === 'deduction') entityBalances[key].deduction += amt; }); // ترتيب العملات المعتمد دائماً const orderedCurrencies = ['EGP', 'USD', 'EUR']; function formatCurrencyDisplay(type) { let parts = []; orderedCurrencies.forEach(curr => { let val = 0; if (type === 'deposit') val = totalsByCurrency[curr].deposit; else if (type === 'deduction') val = totalsByCurrency[curr].deduction; else if (type === 'net') val = totalsByCurrency[curr].deposit - totalsByCurrency[curr].deduction; // تنسيق الرقم والرمز باتجاه يسار-إلى-يمين لمنع التداخل parts.push(`${val.toLocaleString()} ${curr}`); }); return parts.join('  |  '); } document.getElementById('dashTotalDeposits').innerHTML = formatCurrencyDisplay('deposit'); document.getElementById('dashTotalDeductions').innerHTML = formatCurrencyDisplay('deduction'); document.getElementById('dashNetBalance').innerHTML = formatCurrencyDisplay('net'); // تحديث جدول ملخص الجهات const tbodySummary = document.getElementById('entitySummaryTableBody'); tbodySummary.innerHTML = ''; const keys = Object.keys(entityBalances); if (keys.length === 0) { tbodySummary.innerHTML = 'لا توجد بيانات متاحة'; return; } let idx = 1; keys.forEach(k => { const e = entityBalances[k]; const net = e.deposit - e.deduction; let statusBadge = 'متزن (0)'; if (net > 0) statusBadge = 'رصيد لنا'; else if (net < 0) statusBadge = 'مستحق علينا'; const row = ` ${idx++} ${e.entity} ${e.currency} ${e.deposit.toLocaleString()} ${e.deduction.toLocaleString()} ${net.toLocaleString()} ${statusBadge} `; tbodySummary.innerHTML += row; }); }
